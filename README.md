## Polski

### O projekcie

To repozytorium zawiera zbiór przykładowych programów napisanych w języku **BrainFuck** - jednym z najbardziej minimalistycznych języków programowania, jakie kiedykolwiek stworzono. Cały język operuje na zaledwie ośmiu instrukcjach (`> < + - . , [ ]`), a mimo to jest w pełni Turing-zupełny, co czyni go doskonałym materiałem do nauki podstaw działania maszyn obliczeniowych, wskaźników pamięci i logiki niskopoziomowej.

### Zawartość repozytorium

- **`examples/`** - gotowe programy w BrainFuck, uporządkowane według poziomu trudności (od "Hello World" po bardziej złożone algorytmy, np. sortowanie czy obliczenia matematyczne)
- **`docs/`** - krótkie wyjaśnienie składni i zasad działania języka

### Dla kogo jest to repo?

Projekt jest przeznaczony dla:
- osób uczących się programowania i chcących zrozumieć, jak działają komputery "od podszewki",
- entuzjastów języków ezoterycznych,
- nauczycieli i wykładowców szukających materiałów dydaktycznych do zajęć z podstaw informatyki.

### Jak zacząć?

1. Sklonuj repozytorium: `git clone <adres-repo>`
2. Wybierz przykład z folderu `examples/`
3. Uruchom go za pomocą dołączonego interpretera lub dowolnego innego interpretera BrainFuck (np. online)

## English

### About the project

This repository contains a collection of example programs written in **BrainFuck** - one of the most minimalist programming languages ever created. The entire language operates on just eight instructions (`> < + - . , [ ]`), yet it is fully Turing-complete, making it a great tool for learning the fundamentals of computation, memory pointers, and low-level logic.

### Repository contents

- **`examples/`** - ready-to-run BrainFuck programs, organized by difficulty (from "Hello World" to more advanced algorithms such as sorting or basic arithmetic)
- **`docs/`** - a short explanation of the language's syntax and how it works

### Who is this repo for?

This project is intended for:
- people learning programming who want to understand how computers work "under the hood,"
- esoteric-language enthusiasts,
- teachers and instructors looking for teaching material for introductory computer science courses.

### Getting started

1. Clone the repository: `git clone <repo-url>`
2. Pick an example from the `examples/` folder
3. Run it using the included interpreter or any other BrainFuck interpreter (e.g. an online one)
